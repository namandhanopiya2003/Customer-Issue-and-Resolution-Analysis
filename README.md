# CUSTOMER ISSUE & RESOLUTION ANALYSIS

## 🧠 ABOUT THIS PROJECT ==>
- A business analytics project that analyzes customer support data to understand ticket workload, issue patterns, resolution performance, and customer satisfaction.
- Uses SQL, Excel, and Power BI to analyze customer support data and convert the results into structured business insights and recommendations.

## 📋 PROJECT DETAILS ==>

### 1. Project_Guidelines/
Defines the business problem, project objectives, requirements, scope, and key business questions.

### 2. Sample_Dataset/
Contains the raw customer support dataset used as the source for the analysis.

### 3. Data_Cleaning/
Contains the data cleaning process, including data validation, transformation, and preparation of the dataset for analysis.

### 4. SQL_Analysis/
Contains SQL queries used to explore the dataset, calculate key metrics, analyze patterns, and answer business questions.

### 5. Python_Analysis/
Contains Python scripts used for data inspection, analysis, and supporting analytical tasks.

### 6. Excel_Analysis/
Contains structured Excel analysis and analytical tables prepared for comparison, reporting, and Power BI dashboard creation.

### 7. Dashboards/
Contains the Power BI dashboards used to visualize customer support workload, ticket distribution, resolution performance, and customer satisfaction.

### 8. Report_&_Recommendations/
Contains the final project report, key findings, business insights, and recommendations derived from the analysis.

### 9. Output/
Contains the final outputs and deliverables generated throughout the project.
